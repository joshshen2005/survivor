# 最后防线 · 黑夜围城

[在线试玩](https://joshshen2005.github.io/survivor/) · [代码仓库](https://github.com/joshshen2005/survivor)

本地运行：在项目目录执行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后打开 http://127.0.0.1:8765 。游戏使用 ES modules，请通过 HTTP 服务打开。

## 操作与整备

- WASD / 方向键移动，Shift 闪避，Q / E 使用技能，鼠标右键按住手动瞄准。
- B 打开整备，战斗、弹丸、危险区域、刷新和冷却完全冻结。数字 1～6 或点击购买，可连续加点。
- 整备仅手动打开，不再随升级或每分钟自动弹出。选完强化立即继续战斗。
- 退出整备立即恢复战斗，不显示倒计时。仅从暂停继续时显示 3 秒准备倒计时，期间可提前按住移动键；Esc 可取消恢复。空格 / Esc 暂停。
- 从暂停页进入整备，退出时返回暂停页。切换窗口时自动暂停。
- 手机使用左下摇杆、右下技能按钮；整备面板可滚动，继续按钮固定在面板底部。建议横屏。

## 本次调整

- 提亮地面和人物，增加路面颗粒、道路标识、积水、路灯、排水格栅；补充角色肩甲与特殊敌人装甲细节。
- 增加受击方向弧、生命 / 护盾飘字、闪白、震屏与短暂停顿。Web Audio 合成不同的护盾和生命命中声音，默认开启，可关闭。
- 调整敌人生命、伤害、精英率和刷新曲线。Boss 存在期间普通刷新降低，不再叠加多个 Boss。
- 商店价格改用平滑多项式，每次角色升级自动增加 1% 攻击、2 点生命上限并恢复 8 点生命；后期重复成长逐渐放缓。
- 保留原有本地角色动画与素材署名，没有引入额外下载资源。

## 验证

需要 Node.js：

```sh
node --test tests/game.test.mjs
node tests/balance-smoke.mjs
```

第一项覆盖暂停冻结、购买校验、连续升级、禁止自动整备、受击 / 护盾 / 复活、Boss 防重叠和成长上限。第二项用固定种子运行四个职业约 15 分钟的自动战斗，用于观察成长趋势，不能代替真人难度测试。

`http://127.0.0.1:8765/tests/visual.html` 提供独立的受击静帧与音效检查页，不影响正式游戏入口。


## GitHub 部署

这是无需构建的静态游戏，`index.html`、各 JavaScript 模块和 `assets/` 保持在仓库根目录。使用仓库已有的 GitHub Pages（`main` 分支根目录）；推送后由 GitHub 自动部署。`.nojekyll` 确保按静态文件直接发布。

本项目不依赖 npm 第三方包，运行游戏不需要安装 Node.js。开发检查使用 Node.js 22 或更新版本，直接执行 `npm test` 即可，无需 `npm install`。上传前可通过测试命令检查游戏逻辑和全部动画资源；在线部署沿用仓库已有的 Pages 流程。

- `assets/manifest.json`：本地动画清单，路径相对站点根目录。
- `scripts/check-assets.mjs`：检查角色动画组、PNG 文件和必需的运行文件。
- `tests/`：逻辑回归、长期平衡模拟和受击视觉检查。
- `fetch_assets.py` 及素材 ZIP：保留的素材准备工具与原始资源，在线游戏无需执行或下载它们。
